Integration

Open a session in T3 Code

Verified against T3 Code (Beta) 0.1.7 on 2026-11-17. dws uses the bundled CLI to open the workspace; the desktop app adds a missing project.

Found

What T3 Code exposes

  • A bundled CLI at ~/.t3/bin/t3.
  • t3 project add <path> --title <name> adds a project for a workspace root.
  • t3 app [<path>] opens a project in the running desktop app.
  • The t3code:// URL scheme only handles pairing and opening the app, so the CLI is the supported route. dws should never write T3's database directly; it is event-sourced.
Implemented

How dws uses it

  • A new opener, T3 Code, beside your editor: in the Open with dialog, the palette, and after creating a session.
  • The first time, a dialog shows the exact commands. dws then runs them and remembers the choice if you tick it.
  • Default for every session: dws config set opener t3.
  • Failures stay visible: a missing CLI or an error from t3 shows an inline alert, with the output in f2 details.
